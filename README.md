# YouTube to MP3 Converter 🎵

Aplicação Web desenvolvida em Java com Spring Boot que permite extrair o áudio de vídeos do YouTube e convertê-los para download em formato MP3.

Este projeto foi criado com o objetivo de praticar o desenvolvimento Full Stack com Java, explorando o consumo de dados, manipulação de arquivos e interface web.

## 🚀 Tecnologias Utilizadas

- **Java 25 LTS**
- **Spring Boot** (Web MVC)
- **Thymeleaf** (Interface Gráfica)
- **Maven** (Gerenciamento de dependências)
- **IntelliJ IDEA**


## ⚙️ Funcionalidades

- Interface simples para colar o link do vídeo.
- Processamento e extração do áudio no servidor.
- Download automático do arquivo MP3 gerado.

## 📦 Como rodar o projeto

Clone o repositório:
git clone (https://github.com/mauricioffdev/Conversor-YouTube-mp3)

Entre na pasta do projeto: JavaTubeConverter

Execute via Maven: mvn spring-boot:run 

Acesse no navegador: http://localhost:8080
